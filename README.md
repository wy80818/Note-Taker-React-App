## Note Taking App with basic LOCAL ONLY data storage.

This project uses a simple login and user creation setup (as of now) with no real backend, there this 
should only be ran on a machine locally and not connected to the internet.

Install Node.js and git to clone repository.

Use `npm install` and `npm run dev` within reactproject1 directory of the project in the terminal to run.


The site will open on localhost on a ephemeral port.
